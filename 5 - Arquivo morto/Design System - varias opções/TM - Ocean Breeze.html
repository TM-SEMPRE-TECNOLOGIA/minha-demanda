Tipografia

DM Sans (Sans-serif)

A fonte principal do sistema, utilizada para textos gerais, botões e interfaces. Possui excelente legibilidade e múltiplos pesos disponíveis.

Lora (Serif)

Uma fonte serifada elegante, ideal para títulos, destaques e conteúdo editorial que requer uma aparência mais sofisticada.

IBM Plex Mono (Monospace)

Fonte monoespaçada para código, tokens CSS e valores técnicos. Garante alinhamento perfeito de caracteres.
