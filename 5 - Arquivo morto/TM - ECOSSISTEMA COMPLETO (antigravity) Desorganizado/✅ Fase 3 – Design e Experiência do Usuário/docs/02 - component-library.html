✅ Best Practices

Consistência

Use sempre os componentes da biblioteca para manter consistência visual em todo o sistema.

Acessibilidade

Sempre inclua labels, aria-labels e estados de foco visíveis para elementos interativos.

Performance

Evite animações pesadas e otimize imagens. Use loading states para operações assíncronas.
