✨ Princípios de Design

1. Glassmorphism

Uso de transparência e blur para criar profundidade visual.

backdrop-filter: blur(10px); background: rgba(17, 34, 64, 0.5);
2. Micro-animações

Transições suaves de 300ms para feedback visual imediato.

transition: all 0.3s ease;
3. Contraste Adequado

Garantir legibilidade com contraste mínimo de 4.5:1 para texto.

4. Hierarquia Visual

Uso de tamanho, peso e cor para guiar a atenção do usuário.

5. Responsividade

Mobile-first com breakpoints em 768px (tablet) e 1024px (desktop).

🎯 Diretrizes de Uso

Quando usar cada cor:

  • Neon Green: CTAs primários, confirmações, elementos interativos principais
  • Cyan Vibrant: Links, elementos secundários, destaques informativos
  • Success: Mensagens de sucesso, status positivo, validações corretas
  • Warning: Alertas, prazos próximos, atenção necessária
  • Error: Erros, validações falhas, ações destrutivas

Acessibilidade:

  • Sempre testar contraste de cores (mínimo WCAG AA)
  • Não usar apenas cor para transmitir informação
  • Incluir ícones ou texto junto com indicadores coloridos
  • Garantir que elementos interativos tenham estados visuais claros
