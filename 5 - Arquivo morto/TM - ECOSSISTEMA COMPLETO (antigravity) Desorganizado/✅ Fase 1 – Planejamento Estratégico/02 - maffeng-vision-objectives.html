Ecossistema MAFFENG

Automação Técnica

Sistema integrado de aplicativos técnicos, administrativos e gerenciais para automação de relatórios, levantamentos e gestão de contratos

Visão Estratégica

🎯

Objetivo Central

Estruturar um ecossistema integrado que automatize processos técnicos e administrativos, eliminando trabalho manual e aumentando produtividade em campo e escritório.

🔗

Arquitetura Modular

Cada módulo opera de forma independente mas está totalmente integrado via Supabase e autenticação centralizada, permitindo comercialização separada ou em conjunto.

💼

Posicionamento de Mercado

Estabelecer a marca MAFFENG como referência em automação técnica, servindo de vitrine para TM – Sempre Tecnologia e viabilizando transição para pessoa jurídica.

Fluxo de Dados do Ecossistema

O ecossistema segue um fluxo linear com integração bidirecional:

Levantamentos → Gerenciador → Auto Relatórios → Gerenciador → Painel/Ajustes

Nota: O Painel do Diretor recebe métricas de todas as aplicações. TM Administrativo e Financeiro possuem banco de dados separado mas também enviam métricas para o painel central.

Módulos do Ecossistema

Mobile

TM Levantamentos Fotográficos

Usuário: Técnico de Campo

Captura offline de dados e fotos em campo, gerando pacotes ZIP com fotos, JSON e metadados para upload via HTTPS. Distribuído como aplicativo instalável (APK/lojas).

Prototipado - Visual Pronto
Web

TM Gerenciador de O.S.

Usuário: Gerente / Admin Contrato

Núcleo central do ecossistema. Insere ordens de serviço via planilha, recebe e valida pacotes de levantamentos, encaminha ao Auto Relatórios, registra logs e alimenta o Painel do Diretor.

Em Concepção - Núcleo de Integração
Web

TM Auto Relatórios

Usuário: Elaboradores

Motor de geração automática de relatórios .docx usando scripts Python e templates padronizados por contrato. Envia callbacks ao Gerenciador após conclusão.

Inteligência Pronta - Aguarda Integração REST
Web BI

TM Painel do Diretor

Usuário: Diretoria

Dashboard de inteligência de negócios (BI) para visualização de KPIs, SLAs e indicadores consolidados. Lê dados em tempo real do Supabase e permite exportação de métricas.

Conceitual - Aguarda Dados Validados
Web

TM Ajustes Administrativos

Usuário: Administrativo / Financeiro

Controle financeiro, gestão de frota, patrimônio e recursos humanos. Opera em banco de dados separado mas envia métricas consolidadas para o Painel do Diretor.

Conceitual - Expansão Administrativa

Objetivos Estratégicos

  • Eliminar trabalho manual repetitivo através de automação inteligente
  • Garantir consistência e qualidade em relatórios técnicos
  • Centralizar gestão de contratos e ordens de serviço
  • Fornecer visibilidade total do ciclo de vida das O.S.
  • Viabilizar tomada de decisão baseada em dados consolidados
  • Criar ecossistema modular e monetizável
  • Estabelecer marca MAFFENG no mercado de automação técnica
  • Preparar estrutura para transição corporativa (PJ)

Tecnologias e Arquitetura

Backend: Supabase (PostgreSQL) como banco e autenticação central

Frontend: TypeScript + React para aplicações web e mobile

Processamento: Python para geração de relatórios e serviços de backend

Segurança: Autenticação centralizada com JWT e controle de acesso por perfil
