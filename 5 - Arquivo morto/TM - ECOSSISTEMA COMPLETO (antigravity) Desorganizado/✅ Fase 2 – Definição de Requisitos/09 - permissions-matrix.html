6. Implementação com RLS (Row Level Security)

Políticas de segurança a nível de banco de dados (Supabase).

Política: Técnico vê apenas suas O.S.

CREATE POLICY "tecnico_ve_suas_os" ON ordens_servico FOR SELECT USING ( tecnico_id = auth.uid() OR EXISTS ( SELECT 1 FROM usuarios WHERE id = auth.uid() AND perfil IN ('gerente', 'admin') ) );

Política: Isolamento por Contrato

CREATE POLICY "isolamento_contrato" ON ordens_servico FOR ALL USING ( contrato_id IN ( SELECT contrato_id FROM usuarios WHERE id = auth.uid() ) OR EXISTS ( SELECT 1 FROM usuarios WHERE id = auth.uid() AND perfil = 'admin' ) );
