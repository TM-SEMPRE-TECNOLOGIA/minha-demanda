Business Rules

TM Gerenciador de O.S. - Regras de Negócio Consolidadas

Versão 1.0 | Última atualização: Novembro 2025

1. Cálculo de SLA (Service Level Agreement)

Regras para cálculo e monitoramento do prazo de conclusão de Ordens de Serviço.

BR-001
Cálculo de Prazo de O.S.
O prazo de uma O.S. é calculado a partir da data de criação + número de dias úteis configurado por tipo de serviço.
prazo = data_criacao + dias_uteis(tipo_servico)
Exemplo: O.S. criada em 2025-11-01 (sexta)
Tipo: "Levantamento Fotográfico" (prazo padrão: 5 dias úteis)
Prazo: 2025-11-08 (sexta seguinte, desconsiderando fim de semana)
BR-002
Status de Risco de SLA
O sistema deve alertar quando uma O.S. está próxima do vencimento ou já vencida.
Condição Status Ação
Faltam > 3 dias No Prazo Nenhuma
Faltam 1-3 dias Atenção Badge amarelo no dashboard
Faltam < 24h Urgente Notificação para gerente + técnico
Vencida Atrasada Notificação crítica + email
BR-003
Exceções de Prazo
Gerentes podem estender ou redefinir o prazo de uma O.S. com justificativa obrigatória.
Validação: Justificativa mínima de 20 caracteres
Limitação: Extensão máxima de +7 dias úteis
Auditoria: Alteração registrada em status_os

2. Validação de Dados

Regras de validação para garantir integridade dos dados.

BR-010
Validação de CEP
Todo CEP deve ser válido e estar no formato 00000-000.
regex: /^\d{5}-?\d{3}$/
Válidos: 01310-100, 01310100
Inválidos: 1234, 12345-67, abc12-345
BR-011
Unicidade de Número de O.S.
Cada número de O.S. deve ser único por contrato. Não pode haver duplicatas.
UNIQUE CONSTRAINT (numero_os, contrato_id)
Erro ao importar: "O.S. OS-1234 já existe no contrato CTR-2025-001"
BR-012
Campos Obrigatórios na Importação
Na importação via Excel, os seguintes campos são obrigatórios:
Campo Tipo Validação
Número da O.S. String Não vazio, máx 50 caracteres
Endereço String Mínimo 10 caracteres
CEP String Formato 00000-000
Tipo de Serviço String Deve estar na lista pré-definida

3. Atribuição de Ordens de Serviço

Regras para distribuição de O.S. para técnicos.

BR-020
Carga Máxima por Técnico
Um técnico pode ter no máximo 10 O.S. em andamento simultaneamente (status != "concluída" | "cancelada").
COUNT(ordens_servico WHERE tecnico_id = X AND status IN ('distribuida', 'em_campo', 'levantamento_enviado')) <= 10
Erro ao atribuir: "Técnico João Silva já possui 10 O.S. em andamento. Conclua ou redistribua antes de atribuir novas."
BR-021
Atribuição Apenas para Técnicos Ativos
Apenas técnicos com status "ativo = true" podem receber novas O.S.
Validação: Verificar campo usuarios.ativo antes de atribuir
UI: Técnicos inativos aparecem desabilitados na lista de seleção
BR-022
Reatribuição de O.S.
Uma O.S. pode ser reatribuída para outro técnico, mas apenas se ainda não foi concluída.
Permitido: O.S. com status "distribuida", "em_campo"
Bloqueado: O.S. com status "validada", "concluida", "cancelada"
Histórico: Mudança de técnico registrada em status_os

4. Validação de Pacotes de Levantamento

Regras para validação de pacotes enviados por técnicos.

BR-030
Número Mínimo de Fotos
Um pacote de levantamento deve conter ao menos 3 fotos para ser considerado válido.
COUNT(fotos_levantamento WHERE pacote_id = X) >= 3
Frontend: Botão "Enviar Pacote" desabilitado se < 3 fotos
Backend: Validação no endpoint antes de criar pacote
BR-031
Tamanho Máximo de Foto
Cada foto individual não pode exceder 5MB. Fotos maiores devem ser comprimidas no mobile.
Mobile: Compressão automática para max 2MB (qualidade 85%)
Backend: Rejeita upload se > 5MB
BR-032
Aprovação/Reprovação de Pacote
Apenas gerentes podem aprovar ou reprovar pacotes. Reprovação exige feedback obrigatório.
Ação Novo Status Obrigatoriedade de Feedback
Aprovar validado Opcional
Reprovar rejeitado Obrigatório
Feedback Mínimo: 20 caracteres
Notificação: Técnico recebe notificação push com feedback

5. Regras de Permissões (RBAC)

Regras de acesso baseadas em perfil de usuário.

BR-040
Permissões por Perfil
Cada perfil de usuário tem permissões específicas de CRUD.
Perfil Criar O.S. Atribuir O.S. Validar Pacote Ver Todas O.S.
Técnico ❌ ❌ ❌ ❌ (apenas suas)
Gerente ✅ ✅ ✅ ✅ (do contrato)
Admin ✅ ✅ ✅ ✅ (todas)
BR-041
Isolamento por Contrato
Usuários (exceto admins) só podem ver e gerenciar dados do seu próprio contrato.
RLS POLICY: usuarios.contrato_id = ordens_servico.contrato_id
