API Specifications

TM Gerenciador de O.S. - REST API v1.0

Base URL: https://api.maffeng.com/v1

🔐 Autenticação

A API utiliza JWT (JSON Web Tokens) via Supabase Auth.

POST/auth/login

Autentica usuário e retorna token JWT

Request Body:

{
  "email": "ana.rodrigues@maffeng.com",
  "password": "senha123"
}

Response 200:

{
  "access_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "refresh_token": "...",
  "user": {
    "id": "uuid",
    "email": "ana.rodrigues@maffeng.com",
    "perfil": "gerente"
  }
}

Headers para requisições autenticadas:

Authorization: Bearer {access_token}

📋 Ordens de Serviço

GET/ordens-servico

Lista todas as O.S. com filtros e paginação

Query Parameters:

Parâmetro Tipo Descrição
page number Página (default: 1)
limit number Itens por página (default: 20)
status string Filtrar por status
tecnico_id uuid Filtrar por técnico
search string Busca textual

Response 200:

{
  "data": [
    {
      "id": "uuid",
      "numero_os": "OS-4092",
      "status": "em_campo",
      "tecnico": { "id": "uuid", "nome": "Carlos Silva" },
      "endereco": "Rua ABC, 123",
      "prazo": "2025-12-01",
      "created_at": "2025-11-01T10:00:00Z"
    }
  ],
  "meta": {
    "total": 142,
    "page": 1,
    "limit": 20,
    "total_pages": 8
  }
}
POST/ordens-servico

Cria nova O.S. (apenas gerentes)

Request Body:

{
  "numero_os": "OS-4093",
  "contrato_id": "uuid",
  "tipo_servico": "Levantamento Fotográfico",
  "endereco": "Av. Paulista, 1000",
  "cidade": "São Paulo",
  "estado": "SP",
  "cep": "01310-100",
  "prazo": "2025-12-15",
  "prioridade": "alta"
}
PUT/ordens-servico/{id}/atribuir

Atribui O.S. a um técnico

Request Body:

{
  "tecnico_id": "uuid"
}

📦 Pacotes de Levantamento

GET/pacotes-levantamento

Lista pacotes pendentes de validação

Query Parameters:

Parâmetro Tipo Descrição
status string pendente | validado | rejeitado
os_id uuid Filtrar por O.S.
POST/pacotes-levantamento

Cria novo pacote (upload do técnico)

Request Body (multipart/form-data):

{
  "os_id": "uuid",
  "dados_json": { /* dados coletados */ },
  "fotos": [File, File, ...],
  "data_coleta": "2025-11-18T14:30:00Z"
}
PUT/pacotes-levantamento/{id}/validar

Valida ou rejeita pacote

Request Body:

{
  "status": "validado", // ou "rejeitado"
  "feedback_validacao": "Aprovado. Fotos de boa qualidade."
}

📥 Importação de O.S.

POST/ordens-servico/importar

Importa O.S. em lote via Excel

Request Body (multipart/form-data):

{
  "arquivo": File, // .xlsx
  "contrato_id": "uuid"
}

Response 200:

{
  "total_linhas": 50,
  "importadas": 48,
  "erros": 2,
  "detalhes_erros": [
    { "linha": 5, "erro": "CEP inválido" },
    { "linha": 12, "erro": "Endereço obrigatório" }
  ]
}

⚠️ Códigos de Erro

Código Mensagem Descrição
400 Bad Request Dados inválidos no request
401 Unauthorized Token inválido ou ausente
403 Forbidden Sem permissão para esta ação
404 Not Found Recurso não encontrado
422 Unprocessable Entity Validação falhou
500 Internal Server Error Erro no servidor

Formato de Erro:

{
  "error": {
    "code": "VALIDATION_ERROR",
    "message": "Dados inválidos",
    "details": [
      { "field": "email", "message": "E-mail inválido" }
    ]
  }
}

Headers de resposta:

X-RateLimit-Limit: 100
X-RateLimit-Remaining: 95
X-RateLimit-Reset: 1700000000
