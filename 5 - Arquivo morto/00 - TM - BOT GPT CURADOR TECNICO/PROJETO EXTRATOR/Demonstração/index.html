Conferência de RAT 1.0

Automação inteligente para extração de itens de orçamento. Transforme documentos Word em planilhas Excel com precisão e velocidade.

🚀 Como Funciona 📋 Especificações
Funcionalidades

Extração Automatizada de Dados

Recursos avançados para processar relatórios de levantamento com eficiência e precisão

📄

Leitura de Word (.docx)

Processamento automático de documentos Word, identificando e extraindo dados de tabelas específicas.

🔍

Detecção Inteligente

Identifica automaticamente tabelas com cabeçalho "Itens", filtrando apenas dados relevantes.

📊

Exportação Excel

Gera planilhas .xlsx organizadas com códigos e quantidades, prontas para análise.

📝

Log Detalhado

Arquivo de log completo com estatísticas de extração e rastreabilidade de dados.

🔢

Todas as Ocorrências

Lista cada ocorrência de item encontrada, permitindo análise completa do levantamento.

✅

Validação de Códigos

Reconhecimento de padrões como 13.12, 17.7, 2.24, garantindo precisão nos dados.

Processo

Como Funciona

Fluxo simples e intuitivo em apenas 4 passos

1

Selecione o Documento

Escolha o arquivo Word (.docx) contendo as tabelas de itens do relatório.

2

Defina o Destino

Escolha onde salvar a planilha Excel (.xlsx) de saída.

3

Processamento

O sistema identifica tabelas "Itens" e extrai códigos e quantidades automaticamente.

4

Resultado

Receba a planilha organizada + arquivo de log com estatísticas completas.

Técnico

Especificações

Requisitos e detalhes técnicos da automação

Requisitos

  • ⚙️ Python 3.8+
  • 📦 python-docx
  • 📦 openpyxl
  • 🖥️ Tkinter (interface)

Formatos

  • 📥 Entrada: .docx
  • 📤 Saída: .xlsx
  • 📋 Log: .txt

Saída

  • 🔢 Coluna: Código
  • 📊 Coluna: Quantidade
  • 📝 Estatísticas no log

Padrões Aceitos

  • ✓ 17.4, 13.12, 2.24
  • ✓ 19.37, 28.28
  • ✓ Números decimais
# Instalação das dependências
pip install python-docx openpyxl

# Executar a automação
python extrair_itens_docx.py
